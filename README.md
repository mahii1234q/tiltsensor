# Tilt Sensor

This project measures and displays changes in tilt angle using an Arduino and an MPU6050 motion sensor. When the sensor is tilted, the angle readings update on a 20×4 I2C LCD, providing immediate visual feedback.

### Components
- Arduino board
- MPU6050 accelerometer and gyroscope module
- 20×4 I2C LCD
- Connecting wires

### Features
- Real-time tilt angle measurement
- Live angle readings on an LCD
- I2C communication with the sensor and display

The project demonstrates sensor interfacing, I2C communication, and embedded programming using the Arduino IDE.
